# Architecture Decision Records

ADRs formales para Pravia Personalised Mini Books. El ledger de decisiones cross-cutting también vive bajo `docs/decisions/`.

| ADR | Title | Status |
|-----|-------|--------|
| — | (ninguno aún) | — |

## Cuándo crear un ADR

- Decisión que afecta stack, hosting, forma del parámetro de código, o estructura de config
- Trade-offs no obvios que futuros agentes/personas deben entender

## Formato sugerido

Un archivo `ADR-NNN-short-title.md` con Context, Decision, Consequences, Status.
